# Kev-0.8B real acceptance — 2026-11-02

## Environment and scope

- macOS Apple Silicon, M1 Max, 64 GiB unified memory.
- Go 1.27.3; managed Python 3.13; pinned uv 0.13.5.
- Kev revision `2074cc44256200bb37540103fa4572901faa10f3`.
- Model `jaredpalmer/kev-0.8b@v1.0`; sidecar reported **mlx / bfloat16**.
- Fresh temporary `GAVEL_HOME`; actual source/dependency/model downloads and
  actual inference, not stubs. No Kev-4B download or test.
- Command: `make e2e` (`GAVEL_E2E=1 go test ./e2e -run TestRealKev -v -timeout 50m`).

## Results

The final expanded real acceptance test passed in **141.40 seconds** (an earlier
expanded run also passed in 143.24 seconds):

1. Downloaded/verified pinned uv; installed managed Python and synced Kev using
   `uv sync --frozen --no-dev --extra serve --python 3.13`.
2. Prefetched the real adapter, base weights, and tokenizer.
3. Started Kev on loopback and confirmed the MLX backend.
4. Submitted support-ticket state with `noul`, `choice`, and `score` questions
   through the Go console proxy; decoded all three typed answers.
5. Restarted the sidecar with forced offline environment variables and repeated
   inference successfully.
6. Pointed the stopped sidecar at an empty temporary Hugging Face cache;
   confirmed restart failed with `re-run setup` guidance rather than succeeding
   through an online fallback. The saved active model remained unchanged.
7. Separately verified shutdown/reaping of the healthy MLX sidecar immediately
   after offline inference, and cleanup of the failed empty-cache child. Both
   processes exited and their sidecar state files were removed.

The test directed proxy-aware external HTTP(S) requests into a local trap during
ordinary restart, repeat inference, and missing-cache failure. **Zero requests
were observed.** This complements tests of the forced offline environment; it is
not an OS-level packet capture and cannot detect traffic bypassing proxies.

## Bugs exposed and fixed

- Disabled Hugging Face/tqdm progress bars may omit `desc`. The callback now
  tolerates this; a dependency-free Python test reproduces the original failure.
- Kev returns fractional `latency_ms` (observed `1754.9`), not exclusively integer
  milliseconds. Go's response type now preserves the fractional value.

Each bug was reproduced by a failing regression test before the fix. Earlier
real attempts failed at these points, so their results were not counted as
successful acceptance.

## Remaining limits

- Kev-4B, lower-memory Macs, and other Apple Silicon machines remain untested.
- The compiled binary was also launched in an isolated pseudo-terminal: the
  first-run model-selection screen rendered, `q` exited with status 0, and no uv
  download or sidecar state was created. The full interactive download/Ready
  flow was not exercised end-to-end; the browser was smoke-tested against a stub
  previously.
- No real acceptance runs in CI. Normal tests remain model-download-free.
- Each real test removes its temporary cache on completion; rerunning downloads
  the model/runtime again. Default user application data was not modified.
